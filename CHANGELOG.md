# Changelog

## 0.1.0

First release of OpenTV Lite, the Samsung (Tizen) and LG (webOS) edition of OpenTV.

- Add a provider with an Xtream Codes login (paste the whole link and the login fills in) or an M3U playlist
- Live TV with OpenTV's guide: categories, a programme grid, a live preview and now/next details
- XMLTV guide from the provider, streamed so very large guides work on a TV, cached between launches
- Catch-up of past programmes on Xtream channels that offer an archive
- Favourites with the yellow button, channel up/down zapping, reopens on the last channel watched
- Settings: refresh or remove providers
- About: licence, links and the PayPal donation QR code
- 31 languages, chosen from the TV's language setting — the same set as OpenTV for Android
- Typing works with a real keyboard too: start typing on a highlighted field, or click it with a
  mouse or LG's pointer remote
